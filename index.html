Project 2

Project 2 Prototype

Our project is an interactive installation that calms anxious patients in waiting rooms. A Kinect and TouchDesigner turn the visitor's body into the controller for a calming, free-roaming landscape journey (forward, back, left, right, up, down) built from an inported 3D realm. It is designed for waiting-room visitors of all ages, so the interaction has to be simple, intuitive, and low-effort.
